# Jover — site photographe

Site vitrine de Jover, photographe à Lille (mariage & PACS, événementiel, professionnels).

- **En ligne :** https://cordier5943-glitch.github.io/jover-agency-/
- **Dépôt :** https://github.com/cordier5943-glitch/jover-agency-

## Contenu

| Élément | Emplacement |
|---|---|
| Page unique (HTML + CSS + JS) | `index.html` |
| Logo (gris, blanc), favicon | `pics/logo-dark.png`, `pics/logo-white.png`, `pics/favicon.png` |
| Portrait noir et blanc | `pics/jover.webp` |
| Photos du site (WebP optimisées) | `pics/photos/` |
| Publication automatique | `.github/workflows/pages.yml` |

## Modifier le site

Demander à Claude :

> Modifie mon site (dépôt GitHub cordier5943-glitch/jover-agency-), puis envoie la mise à jour sur GitHub.
> Partie à modifier : …
> Ce que je veux : …

Chaque envoi sur la branche `main` republie le site en une à deux minutes
(GitHub → Settings → Pages → Source : **Deploy from a branch**, `main`, `/ (root)` ;
le fichier `.github/workflows/pages.yml` relance la publication automatiquement).
